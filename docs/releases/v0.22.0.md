# Yin 0.22.0 — Compiler Core Preview

Yin 0.22.0 establishes the first executable slice of the multi-target compiler
architecture while preserving the existing hosted runtime as the semantic
reference.

## Highlights

- resolved, typed HIR with stable symbols, source spans, structured data,
  exhaustive matches, policies, and typed JSON boundaries;
- target-independent control-flow MIR with explicit functions, blocks, calls,
  branches, constructors, and match terminators;
- an experimental MIR evaluator covered by differential tests against the
  hosted evaluator;
- source-spanned effect inference with call-graph and callback propagation;
- versioned target profiles and fail-closed `yin check --target` validation;
- new `--emit-hir`, `--emit-mir`, `--run-mir`, and `--target-profiles`
  inspection commands;
- a release Wasm bundle alongside native `yin`, `yinvm`, and VS Code artifacts.

## Target status

- `hosted-v1`: supported;
- `portable-bytecode-v1`: experimental;
- `mir-pure-v1`: prototype evaluator, without a deployable target artifact;
- EVM, SVM, RISC-V, and Bitcoin Script: designed only and rejected by the
  compiler until validators and code generators exist.

This release does not claim general multi-chain compilation. Fixed-width
portable integers, complete module-graph effect binding, target ABIs, resource
models, and the EVM/SVM/RISC-V/Bitcoin backends remain future milestones.
