# Browser ETH wallet demo

This example declares a typed `generate-eth-wallet` tool and displays the
checksummed Ethereum address returned by the Playground's browser host.

The static GitHub Pages runtime generates a secp256k1 key from browser Web
Crypto inside its Web Worker. Yin receives only the address and public key. A
separate one-shot Wasm export transfers the private key to the page, where it is
hidden until the user explicitly reveals or copies it. Resetting the session,
switching examples, generating another wallet, or terminating the Worker clears
the retained reference.

This capability is intentionally unavailable in the native CLI and gateway.
It is an educational demonstration, not an audited wallet product. Never send
funds to an address generated by the demo.
