            Language tour
            
小而清晰的语义边界

          

          
Yin 不是语法玩具：解释器和类型检查器共享一份经过测试的语言规范。

        

        

          

            01
            
词法闭包

            
函数捕获定义位置的环境；交互式重定义不会改写已有闭包。

            
(define make-adder
  (fun (base)
    (fun (value) (+ base value))))

          

          

            02
            
静态类型

            
执行前检查参数、返回值和赋值，错误带有精确源码位置。

            
IntFloatBoolStringAny

          

          

            03
            
联合类型

            
(U Int Float) 表达多种可能，并遵循明确的子类型规则。

            
Int∪Float

          

          

            04
            
名义记录继承

            
记录构造器拥有类型化字段、默认值与传递式名义子类型。

            
(record Point [x Int] [y Int])
(record NamedPoint (Point) [name String])
